## เพิ่มคนและงานเอง

1. **Members → ลงทะเบียน Member**: เริ่มจากชื่อที่ใช้แสดงอย่างเดียวได้ ชื่อจริง ทีม ตำแหน่ง Email เบอร์ และหมายเหตุเติมภายหลังได้ คลิกการ์ดสมาชิกเพื่อแก้ไข/ปิดใช้งาน
2. **＋ เพิ่มงาน**: ชื่องานจำเป็นเพียงช่องเดียว รายละเอียดหลายบรรทัดและ R/A/C/I เติมภายหลังได้ หรือเพิ่ม Member ใหม่จากฟอร์มงาน
3. เลือกสัปดาห์จันทร์–อาทิตย์และ **MoSCoW**: Must ต้องทำ / Should ควรทำ / Could มีเวลาแล้วทำ / Won’t ไม่ทำรอบนี้ เว้น priority ว่างได้
4. คลิกการ์ดงานเพื่อเติมรายละเอียด เปลี่ยนคน/priority หรือดูประวัติ ย้ายสถานะด้วยการลากหรือเมนูสถานะ การเลือกสัปดาห์ใหม่เพิ่มแผนรอบใหม่ให้ task เดิมโดยไม่ลบประวัติรอบก่อน

**Won’t** แสดงในชั้น “ไม่ทำในรอบนี้” ไม่ถือเป็น Done ตัวเลขผลงานนับเฉพาะ M/S/C; งานที่ยังไม่จัดลำดับแสดงแยก งานเริ่มต้น 5 รายการยังรอยืนยันสถานะ/A และยังไม่มี priority ที่ระบบตัดสินใจแทน

ก่อนเปลี่ยนเป็น **เสร็จแล้ว** ต้องมี R, A ที่ยืนยันในเครื่อง, เกณฑ์รับงานที่ยืนยัน และหลักฐานส่งงาน ถ้าผูก KPI ต้องระบุวันตรวจผลซ้ำ การยืนยันในเครื่องไม่ใช่การ login หรือการอนุมัติจากบุคคลนั้น

## เชื่อมประชุมจาก FUNG

1. ใช้ FUNG build ที่มี adapter ใหม่ เปิด Settings → Runtime แล้วคัดลอก Connect URL
2. **Meetings → ตั้งค่าการเชื่อมต่อ** วาง URL ของ FUNG บนเครื่องนี้ Token อยู่ในหน่วยความจำเฉพาะการเปิดหน้า Meetings และไม่รวมใน Backup
3. เลือกประชุมที่ถอดเสียงแล้ว หรืออัปโหลดไฟล์แล้วกดตรวจสถานะถอดเสียงจนสำเร็จ ไม่ใช้ transcript ว่างเป็นประชุมที่พร้อมทำงาน
4. แก้ข้อความ/ชื่อผู้พูด ฟังเสียงด้วยช่องที่มี แล้วกด **บันทึกฉบับตรวจแล้ว** ต้นฉบับและ timecode ไม่เปลี่ยน
5. กดสร้างร่างด้วย FUNG ตรวจ quote เลือก R, สัปดาห์ และ MoSCoW ก่อนสร้างงาน ชื่อผู้พูดไม่ถูกมอบหมายอัตโนมัติ ร่างใหม่ของประชุมที่เคยสร้างงานให้เลือกผูก/อัปเดต/สร้างใหม่ทีละรายการ
6. ถ้าโมเดลไม่พร้อม ใช้ **สร้างงานเองจากช่วงนี้** โดยระบุว่าเป็นงาน Manual พร้อมหลักฐานจากฉบับตรวจ

## Backup และงานที่ผูกแคมเปญ

**Backup JSON** รวมแคมเปญ สมาชิก งาน แผนสัปดาห์ transcript/review และประวัติ แต่ไม่รวม token หรือไฟล์เสียง **Restore backup** ตรวจจำนวนก่อนยืนยันและดาวน์โหลดชุดเดิมเก็บไว้ รองรับ Backup แคมเปญ v1 โดยคง Meeting & Task Manager เดิม

เลือก Campaign ในรายละเอียดงานเพื่อให้แสดงใน Workboard แคมเปญ การ์ดที่เชื่อมเปิดกลับมายัง task เดิม ไม่มีสำเนางานอีกชุด
