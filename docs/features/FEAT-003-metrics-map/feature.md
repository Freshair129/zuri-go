# FEAT-003 — Marketing Metrics Map and Graph View

A Thai reference guide that connects marketing metrics to customer growth, team responsibilities and planning — 18 guide pages and 40 graph terms — with an interactive 2D/3D Graph View of the same terms. It is static content served at `/metrics/`; it holds definitions and hypothetical examples, never live performance data.

## Scope
- Guide pages 01–18 in six print categories: 38 metric cards plus MQL and SQL (REV 04 adds actual Media Spend, Revenue and Overstock SKU).
- Graph View: node search, category browse, 2D/3D, rotation, zoom, three backgrounds and a detail panel; web-only and hidden in print.
- Generated by `scripts/metrics` into `apps/metrics`; generated HTML is rebuilt, not hand-edited.

## Ownership
- Feature owner: [DOM-MET](../../domains/metrics/README.md) — Metrics & goals. Type: domain feature, no cross-domain participants.
- Runtime owner: [SRV-001](../../services/SRV-001-hosted/SERVICE.md) in production; the trusted local operator runs it on [SRV-002](../../services/SRV-002-local/SERVICE.md).
