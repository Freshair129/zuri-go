# FR-003-001 — An 18-page guide in six categories with a linked contents

The guide SHALL have 18 numbered pages in six print categories — Overview (01), A · Metrics (02–06), B · Growth (07), C · Team & Workflow (08–09), D · Planning (10–13), E · Commerce & Operations (14–17) and F · Reading & Sources (18) — each page carrying its number, its category name and one main question, with a table of contents that links to every page.

## Acceptance criteria
- AC-003-001-01 — Given the guide, then it has exactly 18 pages in the order above.
- AC-003-001-02 — Given each page, then it shows its page number, its category name and its main question.
- AC-003-001-03 — Given the table of contents, when a link is followed, then it opens the page it names and the page number agrees.
- AC-003-001-04 — Given the categories, then Metrics covers Awareness, Consideration, Conversion, Revenue & Profit and Customer Value; Growth covers AARRR; Team & Workflow the team and the working loop; Planning KPI & Budget, RACI, the 90-day roadmap and the 12-month outlook; Commerce & Operations four pages; and the last page the reading checklist and the sources.

## Implementation
- `scripts/metrics/build_metrics_map.py` (the page list); `scripts/metrics/verify_metrics_map_static.py` counts the guide pages and checks every local anchor.
- Static audit of the generated guide (18 pages, 38 metric cards, 40 graph terms, no missing file or anchor): `scripts/metrics/verify_metrics_map_static.py`, run by `npm test` and `npm run build`; its extraction-time report is [static-checks.json](../../../migrations/verification/metrics/static-checks.json).
